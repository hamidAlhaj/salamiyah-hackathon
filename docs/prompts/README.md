# برومبتات تحسين شبكة تبرعات السلمية

أعطِ مساعد البرمجة صلاحية قراءة مستودع المشروع ثم انسخ له **ملف مرحلة واحداً كاملاً**. كل ملف هو طلب تنفيذ مستقل فيه نقطة بداية وشروط قبول. استندت المراحل إلى مراجعة النسخة `acefc90`. إذا تطوّر المشروع بعدها، يبدأ المساعد من الفرع الحالي ويتحقق مما أُنجز.

| الترتيب | الملف | النتيجة المطلوبة |
|---|---|---|
| 01 | [سلامة العمليات المالية](01-financial-integrity.md) | صرف ضمن الرصيد، وقرار واحد لكل عملية تدقيق |
| 02 | [خصوصية المستفيد والإيصال](02-privacy-and-receipts.md) | سجل صرف عام مجهول وإيصال اسمي محمي |
| 03 | [واجهة المجلس والشفافية](03-council-and-transparency.md) | إدخال المصروف، نشر حملة مكتملة، وأرقام دقيقة |
| 04 | [استلام الكاش](04-cash-collection.md) | تأكيد التعهّد نفسه في نقطة الجمع |
| 05 | [إشعارات المتبرع](05-donor-notifications.md) | تأكيد على الويب والموبايل وربط إيصال آمن |
| 06 | [تجربة المتبرع](06-donor-access.md) | تسجيل على الويب، جلسة موبايل تتحمل انقطاع الشبكة، وتصفح كل الحملات |
| 07 | [اختبار التسليم](07-acceptance.md) | تجربة مشتركة من الهاتف إلى لوحة المجلس بأرقام قابلة للمطابقة |

نفّذوا المراحل بالترتيب إذا عم تشتغلوا بمحادثات منفصلة. يمكن لشخص من الفريق تنفيذ 06 بالتوازي بعد الاتفاق على ملفات المصادقة. ادمجوا تغييرات المراحل السابقة قبل اختبار 07. احتفظوا بنتيجة فحوص كل مرحلة مع التغيير حتى تعرفوا أي جزء جُرّب فعلياً.
